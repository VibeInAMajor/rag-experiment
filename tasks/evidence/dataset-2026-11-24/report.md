## Реальный результат: OPEN V2

31 оригинал прошёл существующую загрузку через ASGI HTTP, parser/chunker и PostgreSQL. Пять отказов Markdown HTTP 413 сохранены; разрешённые source-only TXT line windows дали 144 представления/1080 чанков без изменения оригиналов или лимитов. Все 1080 чанков получили настоящие Qwen3-Embedding-4B embeddings размерности 2560. Свежая штатная калибровка измерила 589824 tokens/min; старый истёкший допуск не переиспользовался.

Выполнено 306 dense и 306 FTS запросов, включая 261 ответный и 45 безответных, в 102 семействах EN/RU/UK. Для каждого dense-запроса прямой read-only SQL совпал с HTTP по ID, порядку и cosine distance: **306/306**. Вопросы передавались как opaque ID+text, эталоны не попадали в индекс/запрос. Predictions заморожены до scoring; параметры модели и запроса не подгонялись под результат.

Ниже усреднено покрытие **известных обязательных диапазонов источника** по 261 ответному вопросу. Полный факт засчитывается, когда весь один допустимый набор его доказательств покрыт объединением полученных чанков. Все варианты/переводы одновременно не требуются.

При dense top-5 все обязательные факты покрыты в 222/261 вопросах; в 39 покрытие неполное, из них 15 без единого полного размеченного факта. При top-10 полное покрытие 232/261, без единого полного факта остаются 9. Это диагностический baseline с наблюдаемыми пробелами, а не достигнутая полнота ответов.

**FTS:** все 306 исходных вопросов дали пустую выдачу. Существующий `plainto_tsquery('simple', query)` требует конъюнкции всех лексем полного вопроса, без семантического перефразирования. Отдельный контроль того же FTS-пути на 3 оригиналах/257 чанках прошёл 10/10 буквальных запросов из нативных лексем; сохранённый search_vector совпал с нативным to_tsvector. Первоначальный контроль из regex-фрагментов не прошёл и не засчитан; корректный контроль использует словарь самого PostgreSQL. Исходные 306 вопросов и predictions не переписывались.

Для всех 45 вопросов без ответа dense вернул соседей. Генератор и решение answerability не запускались, поэтому false acceptance/false abstention не измерялись. Неразмеченные чанки сохранены как unknown: полные graded nDCG и relevance Recall не вычислялись и не заменялись выдуманными нулями. Исходная разреженная разметка фактов/альтернатив/explicit negatives сохранена.
